# RADAR：评分不独立性与实验限制

来源：[arXiv:2608.01810v1](https://arxiv.org/abs/2608.01810v1)。本文沿用已审核的主表及证据边界。

## 如何理解“不正交”

同一套 Rubric 内不同条目可能没有提供独立的评分信号。例如，提高正确性时，有用性也可能跟着升高，两项加总可能重复奖励同一部分质量。RADAR 定向生成某条标准的高、低分回答，再检查其他条目的评分是否跟随变化，以及这种关系是否双向。

方法主要推进到检测与量化依赖。是否合并条目、调整权重或保留合理层级，仍由人判断；论文没有完成自动修正闭环，也未直接验证修正后的人机一致率或模型排名质量。

## 预审中保留的限制

- 模型敏感性明显：附录 Table 9 中，SumPubMed 的某些组合 Pearson 低至 −0.04，不能概括为所有组合都达到 0.84。
- 小样本实验存在内部不一致：附录 G 文字称 SummEval 因未保留探针评分而排除，但 Table 13 又列出其结果；“全部预算均 ≥0.84”的表述也与部分表中数值不符。
- 复现参数待核实：§4.2 的生成温度为 0.7，§3.2 与附录 Table 8 为 0.9。
- 定向生成可能同时改变多个回答属性，因此方向性泄漏只能提供行为证据；人类评分相关性也不是依赖关系的金标准。
