# ARES: Automated Rubric Synthesis for Scalable LLM Reinforcement Learning

已审核草稿 v2，2026-09-16 入库。

[论文 v2](https://arxiv.org/abs/2605.23454v2)

## 数据集与实验

从 DCLM、FineWeb-Edu 和 FinePDFs 的约 0.1B tokens 文档池构造出 101,847 条实例，覆盖十个领域，共含 1,108,163 条标准，平均每题 10.88 条。

实验基于 Qwen3-4B-Base，在知识推理、数学、代码、医疗、写作和指令遵循的七项基准上评测：

| 训练方式 | 七项平均 | HealthBench | IFEval |
|---|---:|---:|---:|
| 继续预训练 CPT | 47.36 | 35.04 | 39.39 |
| Webscale 二元奖励 RL | 48.30 | 36.08 | 35.61 |
| ARES-SFT | 49.71 | 35.78 | 46.41 |
| ARES-RL | 52.69 | 41.45 | 54.88 |

ARES-RL 比同数据的 ARES-SFT 平均高 2.98 分，比 Webscale 高 4.39 分。这些结果说明合成标准能够提供有效的训练信号；实验范围仍限于一个基座模型与固定 Judge，未报告真实业务部署效果。
